# Minhas Viagens Android

Este módulo cria um APK Android independente da instalação PWA do Chrome.

O APK é uma casca nativa WebView que carrega:
https://lcmsarq-creator.github.io/minhas-viagens/

As atualizações de interface e lógica continuam sendo publicadas pelo GitHub Pages,
portanto não é necessário recompilar o APK a cada alteração web.

O workflow `android-apk.yml` gera um APK de instalação pessoal como artefato.
